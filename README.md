# tahiry.world – статическая копия

Страница, картинки, видео и звук сайта https://tahiry.world. Отсюда их берёт Gcore CDN для посетителей из-за границы и с VPN.
PHP (заказы, оплата, страница заказов) работает только на основном хостинге и сюда не попадает.

При каждом обновлении сайта класть сюда те же `index.html`, `img/`, `video/`, `sound/`, что и на хостинг.
